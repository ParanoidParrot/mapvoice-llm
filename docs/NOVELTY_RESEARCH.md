# Related-work / novelty notes

This file exists to keep public positioning evidence-based.

## Known adjacent public datasets

### Koel Benchmark Suite
A multilingual Indian TTS benchmark that includes a locality split for Indian place-name pronunciation across Hindi, Tamil, Telugu, Kannada, Malayalam and Marathi.

MapVoice should therefore **not** claim to be the first Indian locality/place-name pronunciation dataset.

### AI4Bharat Naamapadam
A large named-entity annotated corpus for 11 Indic languages, including Kannada, Tamil, Telugu, Marathi and Malayalam.

MapVoice is not claiming novelty in general Indic named-entity data.

## Current MapVoice differentiation

The narrower contribution being developed is:

- city-specific navigation toponyms rather than general NER;
- an explicit candidate → provenance → independent review → adjudication lifecycle;
- city/language regional packs;
- entity-held-out evaluation for unseen place names;
- navigation-context SFT generation;
- LoRA adapter lifecycle per regional pack;
- a planned public dataset + regional adapter family.

Suggested public wording:

> An early city-specific, provenance-aware dataset and model-development pipeline for Indian navigation toponyms across Bengaluru/Kannada, Chennai/Tamil, Hyderabad/Telugu, Mumbai/Marathi and Kochi/Malayalam.

Avoid "first" unless a later literature/dataset survey supports a precisely scoped priority claim.
